FAQ

Questions, answered.

How fast does an answer appear?

Response time varies by provider, model, network, and request type. MockMate streams results as they arrive and uses fast-path routing where appropriate.

Is the overlay hidden from screen sharing?

Windows and macOS have a supported OS content-protection path, but capture behavior varies. Always verify the actual meeting-app share preview. Linux content protection is not supported.

Is my data private?

BYOK credentials stay on your device. Prompts, audio, screenshots, and other inputs may still be sent to the AI or transcription providers you configure. Managed services use the hosted MockMate backend where enabled.

Do I need an API key?

Managed services may be available when configured for your account/environment. BYOK is also supported with compatible providers.

Does MockMate work with Zoom, Meet, and Teams?

Live uses system audio, so it can work alongside common meeting platforms. Verify audio capture and share-preview behavior on your actual device before an important interview.

Which platforms are publicly available?

The current automated public v1.5.2 release artifact is Windows. macOS and Linux runtime/packaging code remain in the project, but this page does not advertise them as current v1.5.2 public downloads.
