# MockMate v1.6.2

Signed public Windows release candidate incorporating model-routing, audio-readiness and desktop UX fixes.

- Automatic provider routing replaces Live/Solo model dropdowns. Defaults, priorities and official API-key links share one registry; compatible discovered models can recover unavailable defaults.
- Actionable AI errors distinguish credentials, access, model availability, request format, limits and outages.
- Ready Room tests microphone or system playback, carries the source into Live and resets voice readiness after device changes. Microphone questions require explicit Answer this.
- Fix collapsed badge size/transparency, dashboard dragging/resizing, responsive navigation, scrolling and sticky key-save controls.
- Stable release requires trusted app/installer signatures. Public release and updater assets are published only after verification; no unsigned stable fallback.

Package, root lock and tag target: 1.6.2 / v1.6.2. Desktop versioning remains separate from backend/mobile package versions.

Real provider credentials, Windows install/headphone capture/share preview, Authenticode trust and signed updater delivery need workflow/device evidence. This file does not claim the candidate is already published or physically certified.
