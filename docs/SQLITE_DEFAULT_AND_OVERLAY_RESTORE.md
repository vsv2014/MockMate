# SQLite default and overlay restoration

SQLite is now the default desktop session store. The raw account-scoped localStorage import runs on first async History access/write in the updated Electron application, retains the source, verifies every imported row and preserves existing IDs. No data on a user's Windows machine was accessed or migrated by this development environment. No production sessions were available here to migrate. Browser mode remains localStorage. MOCKMATE_SQLITE_PILOT=0 is an explicit recovery override; it will not display newly captured SQLite sessions. Secure-storage/database failures remain explicit rather than silently downgrading writes.

The overlay restore path previously sent a separate native resize before React's pill -> overlay mode update. That resize can be discarded while main still reports pill mode. Expanded constraints also need to be reset after changing native resizability, because Windows may retain a pill-sized maximum. Restoration now sends mode + size together, enables resizing before clearing maximum bounds, then restores expanded minimums. Main rejects pill-sized/undersized restore geometry by choosing a readable size (normally at least 600 x 600, clamped to display work area). Manual resize while expanded remains available. Requested/observed restore sizes are logged without private content.

Tests exercise cached native constraints, stale 72/73-pixel dimensions, small-display clamping and the actual main mode handler. These tests are simulations, not proof of Windows compositor behavior. Packaged Windows collapse/expand/drag/restart and SQLite import/key recovery remain release gates. This change does not add hosted sync, automatic later schema migrations or full ARCH memory/coaching. It does not publish a release.
